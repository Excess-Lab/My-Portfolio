# My Portfolio

Сайт-портфолио. Vite + Lit + GSAP + Tailwind, деплой на GitHub Pages.

## Разработка

```bash
npm install
npm run dev
```

Сборка: `npm run build`, локальный просмотр собранного: `npm run preview`.

## Что сейчас сделано

Титульный экран «оторви и войди»:

- фигура с постером из макета Figma (node `1:8`);
- отрывной хлястик тянется мышью, пальцем или с клавиатуры (Tab → Enter);
- разрыв идёт по рваному краю: под полосой лежит надорванный слой, маска
  повторяет его контур (`src/lib/tear-mask.js`);
- звук разрыва синтезируется на Web Audio и реагирует на скорость руки
  (`src/lib/tear-sound.js`). Если положить `public/sfx/tear.mp3`, он подхватится
  автоматически вместо синтеза;
- после отрыва бумага падает с физикой — гравитация, сопротивление воздуха,
  планирование (`src/lib/paper-physics.js`), и только затем фигура распадается
  на атомы (`src/lib/atomize.js`);
- дальше — основной сайт, пока пустая белая страница (`#site` в `index.html`).

Три языка: русский, english, Српски. Тексты — в `src/i18n/index.js`, выбор
запоминается в localStorage.

## Шрифт

Макет свёрстан в PT Astra Serif; сейчас подключена PT Serif (тот же исходник).
Чтобы поставить настоящую: положить `woff2` в `public/fonts/` и раскомментировать
блок `@font-face` в `src/styles/main.css`.

## Деплой на GitHub Pages

Workflow `.github/workflows/deploy.yml` собирает и публикует `dist/` при пуше
в `main`. Один раз нужно включить Pages: **Settings → Pages → Source: GitHub
Actions**.

Пути к ассетам относительные (`base: './'`), поэтому сайт одинаково работает
и на `excess-lab.github.io/My-Portfolio/`, и на своём домене.

### Домен makark.ru

`public/CNAME` с доменом уже лежит в репозитории — без него Pages сбрасывает
домен при каждом деплое.

Осталось прописать DNS у регистратора:

- четыре `A`-записи для `makark.ru` → `185.199.108.153`, `185.199.109.153`,
  `185.199.110.153`, `185.199.111.153`
- `CNAME` для `www` → `excess-lab.github.io`

После того как DNS разойдётся, в **Settings → Pages** проверить, что домен
подхватился, и включить **Enforce HTTPS**.
