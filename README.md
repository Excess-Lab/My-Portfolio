# My Portfolio

Сайт-портфолио. Vite + Lit + GSAP + Tailwind, деплой на GitHub Pages.

## Разработка

```bash
npm install
npm run dev
```

Сборка: `npm run build`, локальный просмотр собранного: `npm run preview`.

## Что сейчас сделано

Титульный экран «оторви и войди»:

- фигура с постером из макета Figma (node `1:8`);
- отрывной хлястик тянется мышью, пальцем или с клавиатуры (Tab → Enter);
- разрыв идёт по рваному краю: под полосой лежит надорванный слой, маска
  повторяет его контур (`src/lib/tear-mask.js`);
- звук разрыва синтезируется на Web Audio и реагирует на скорость руки
  (`src/lib/tear-sound.js`). Если положить `public/sfx/tear.mp3`, он подхватится
  автоматически вместо синтеза;
- после отрыва бумага падает с физикой — гравитация, сопротивление воздуха,
  планирование (`src/lib/paper-physics.js`), и только затем фигура распадается
  на атомы (`src/lib/atomize.js`);
- дальше — основной сайт, пока пустая белая страница (`#site` в `index.html`).

Три языка: русский, english, Српски. Тексты — в `src/i18n/index.js`, выбор
запоминается в localStorage.

## Как добавить кейс

Всё содержимое раздела «кейсы» лежит в одном файле — `src/data/cases.js`.
Компонент только раскладывает то, что там описано, вёрстку трогать не нужно.

### 1. Положить превью

Файл кладётся в `public/cases/`. Имя — латиницей, без пробелов.

- картинка: `jpg`, `png`, `webp`;
- видео: `mp4`, `webm`, `mov` — подхватится само, отдельного флага нет,
  расширение решает всё (`isVideo` в том же файле). Видео проигрывается
  зациклено, без звука;
- пропорции кадра — **16:10**, всё лишнее обрежется по центру. Ширины 1600 px
  хватает с запасом, тяжелее заливать незачем.

### 2. Дописать объект в `CASES`

```js
{
  id: 'nevarliki',                 // короткий латинский идентификатор, уникальный
  year: '2026',                    // показывается рядом с категорией
  category: 'web',                 // ключ из CATEGORIES, см. ниже
  preview: 'cases/nevarliki.jpg',  // путь от public/, без ведущего слэша
  title: {                         // название по языкам
    ru: 'неварлики',
    en: 'nevarliki',
    sr: 'неварлики',
  },
  description: {
    ru: 'одно-два предложения: контекст, что сделал, результат.',
    en: 'english version — optional',
    sr: 'српска верзија — optional',
  },
  link: 'https://nevarliki.ru',    // необязательно: делает всю карточку ссылкой
}
```

Обязательные поля — `id`, `year`, `category`, `preview`, `title` и `description.ru`.
Нет перевода — подставится русский, ничего не сломается. `title` можно задать
и просто строкой, если переводить нечего: `title: 'неварлики'`. Нет `link` —
карточка просто не будет кликаться.

Порядок в массиве = порядок в ленте. Лишний проект убирается удалением его
объекта.

### 3. Категории

Список — в `CATEGORIES` наверху того же файла: `product`, `brand`, `web`,
`motion`, `research`. Нужна своя — добавляется строкой:

```js
export const CATEGORIES = {
  // ...
  ux: { ru: 'исследование ux', en: 'ux research', sr: 'ux истраживање' },
};
```

и дальше в кейсе пишется `category: 'ux'`.

### 4. Поиск

Ничего настраивать не нужно: поле над лентой ищет по всем словам сразу —
по названию, году, категории и описанию. Совпасть должны все введённые слова,
но каждое может стоять в своём поле, поэтому «сайт 2025» находит проект,
у которого категория «сайт», а год — 2025. Счётчик под полем показывает,
сколько нашлось.

### 5. Выложить

```bash
git add -A && git commit -m "Add case: неварлики" && git push
```

Пуш в `main` запускает workflow — через пару минут кейс на сайте.
Локально проверить до пуша: `npm run dev` и открыть `?screen=cases`.

## Как добавить мысль в архив идей

Файл — `src/data/ideas.js`, устройство такое же простое:

```js
{
  id: 'interface-as-a-sentence', // короткий латинский идентификатор
  date: '2026-07-14',            // ГГГГ-ММ-ДД, по ней и сортируется лента
  title: {                       // можно и строкой, если переводить нечего
    ru: 'интерфейс как фраза',
    en: 'an interface is a sentence',
    sr: 'интерфејс као реченица',
  },
  text: {
    ru: `первый абзац.

  второй абзац — их разделяет пустая строка.`,
  },
}
```

Новые мысли встают наверх сами: порядок в массиве не важен, лента сортируется
по `date`. Дата выводится словами на языке сайта — «14 июля 2026», «14 July
2026», — писать её руками не нужно.

Текст в шаблонных кавычках (` `` `), абзацы разделяются пустой строкой.
В ленте мысль показана заголовком с датой, а по нажатию раскрывается на месте.
Поиск работает по всем переводам, тексту и дате.

Смотреть локально: `?screen=archive`.

## Шрифт

Макет свёрстан в PT Astra Serif; сейчас подключена PT Serif (тот же исходник).
Чтобы поставить настоящую: положить `woff2` в `public/fonts/` и раскомментировать
блок `@font-face` в `src/styles/main.css`.

## Деплой на GitHub Pages

Workflow `.github/workflows/deploy.yml` собирает и публикует `dist/` при пуше
в `main`. Один раз нужно включить Pages: **Settings → Pages → Source: GitHub
Actions**.

Пути к ассетам относительные (`base: './'`), поэтому сайт одинаково работает
и на `excess-lab.github.io/My-Portfolio/`, и на своём домене.

### Домен makark.ru

`public/CNAME` с доменом уже лежит в репозитории — без него Pages сбрасывает
домен при каждом деплое.

Осталось прописать DNS у регистратора:

- четыре `A`-записи для `makark.ru` → `185.199.108.153`, `185.199.109.153`,
  `185.199.110.153`, `185.199.111.153`
- `CNAME` для `www` → `excess-lab.github.io`

После того как DNS разойдётся, в **Settings → Pages** проверить, что домен
подхватился, и включить **Enforce HTTPS**.
